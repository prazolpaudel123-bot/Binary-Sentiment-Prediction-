# Binary-Sentiment-Prediction-
Binary Sentiment Prediction creates label  from rating (≥ 7.5 = Positive, else= Negative) using the sequential data as descriptions of movies IMDB dataframe.
Source: https://www.kaggle.com/datasets/lakshmi25npathi/imdb-dataset-of-50k-movie-reviews. 
Download all (.py, .ipynb, .pkl, .h5) files in a folder In RNN_IMDB.ipynb file, go to terminal and run streamlit To run streamlit, go to terminal of the .py file and enter py -m streamlit run "file_location\RNN_IMDB.ipynb" 
For example, in my device I enter: py -m streamlit run "L:\Softwares\VS Code\Files\RNN\imdb_binary_sentiment\RNN_IMDB.ipynb" 
A localhost appears in your default web browser and finally you are about to predict sentiment label on the basis of your own description (short story/ abstract) of a movie/ web-series.
